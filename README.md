## Descripción
Este proyecto grupal se ha generado en el contexto de un bootcamp para manejar el desarrollo Full Stack de Java. Ha ido creciendo en base a lo que hemos aprendido y practicado clase a clase en conjunto con todos los integrantes del bootcamp y nuestros profesores, partiendo desde HTML , agregando estilos con CSS y luego interactividad con JS, usando bibliotecas como Bootstrap y JQuery. Cada participante ha creado sus paginas personales y ha trabajado en ellas demostrando cada avance con la creación de diferentes ramas de trabajo.
